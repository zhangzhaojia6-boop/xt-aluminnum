# 企业微信生产入口准备清单

当前正式身份入口优先走浏览器和钉钉 H5。企业微信群机器人可保留为消息发送能力，但不作为登录入口。

## 当前路由

- 浏览器可直接访问 `/entry` 与 `/manage/factory`。
- 手机填报入口：`https://<你的正式域名>/entry`。
- 审阅入口：`https://<你的正式域名>/manage/factory`。
- 旧 `/mobile` 可兼容跳转到 `/entry`。

## 上线前确认

1. 域名 HTTPS 正常。
2. 管理员账号可登录。
3. 试点车间账号权限正确。
4. 企业微信消息能力不影响身份登录链路。
