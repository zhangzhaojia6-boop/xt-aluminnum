# 部署文档

鑫泰铝业 数据中枢生产部署以 GitHub 和云主机为主线。云主机只从 GitHub 拉取已合并代码，不在服务器上手工改业务文件。

## 发布前提

- GitHub 已配置远端。
- 云主机可执行 `git pull`。
- 发布冻结以 `main == origin/main` 且 `git status --short` 为空为前提。
- 先选择一个车间做正式试跑。
- 企业微信正式入口先不接。
- 现场主数据已具备初始化脚本与 `/readyz` 闸门。
- 正式试跑前需按目标车间复核车间、班次、角色、模板、专项 owner、管理员账号。
- 现场主数据和试点账号尚需最终过一遍。

## 标准流程

```bash
git fetch origin
git pull --ff-only origin main
./scripts/deploy_trial.sh
./scripts/check_trial_stack.sh
```

试跑通过后，再执行生产发布脚本并检查 `/healthz`、`/readyz`、`/entry`、`/manage/factory`。
