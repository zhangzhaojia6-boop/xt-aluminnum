# Hermes Factory Super Brain Closed Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Hermes into a closed-loop `鑫泰铝业 数据中枢` factory super brain that understands DingTalk natural language, normalizes factory data, plans tool calls, shows progress, generates artifacts, learns from feedback, and can request Codex construction work.

**Architecture:** Extend the existing factory brain lane instead of creating a second agent. DingTalk inbound continues to enter `run_factory_brain_turn()`, the LangGraph app becomes the single state machine for intent, normalization, planning, evidence, RAG, artifact requests, feedback, and response. Existing MES/WMS/data hub/DingTalk/RAG/Codex services stay as source and action adapters.

**Tech Stack:** FastAPI, SQLAlchemy `2.0.30`, Alembic `1.13.1`, PostgreSQL, pytest `8.2.2`, pandas `2.2.2`, openpyxl `3.1.2`, httpx `0.27.0`, LangChain `1.3.11`, LangGraph `1.2.6`, `langgraph-checkpoint-postgres` `3.1.0`, `psycopg[binary,pool]` `3.3.4`, existing DingTalk inbound/outbox, existing RAG and Hermes factory brain services.

## Global Constraints

- Use product name `鑫泰铝业 数据中枢`; do not call the data hub a MES system.
- MES remains high-permission read-only.
- WMS, DingTalk texts/files, historical daily reports, and the data hub are official data sources.
- `root_owner` is 张兆嘉; other users cannot create Codex construction work or promote formal knowledge.
- Business numbers must carry internal source, date, unit, business definition, and confidence.
- Show auditable work stages in DingTalk cards; do not expose hidden model chain of thought.
- Natural language is the user interface; slash commands are not required.
- Rule-based common business intent detection runs before model fallback.
- RAG is not a numeric fact source.
- Use Meta Skill to produce new skill packages after checking mature GitHub skill/agent designs.
- SQL/API/file parsing takes priority over browse; browse takes priority over computer use.
- Keep the existing command/RAG fallback lane intact.
- Keep changes surgical and follow current backend service/test style.

The spec spans intent routing, normalization, evidence, RAG, DingTalk UX, artifacts, feedback learning, Meta Skill, browse/computer use, and acceptance testing.

Keep one master plan because the features must meet in the same `FactoryBrainState` and DingTalk entrypoint. Execute it as vertical slices. Each task leaves the system testable and commit-ready.

from __future__ import annotations

from app.services.hermes_factory_brain_types import FactoryBrainIntent, FactoryBrainNormalizedRequest


_WORKSHOP_ALIASES = {
    '1650冷轧': '1650',
    '1650车间': '1650',
    '1650机组': '1650',
    '1850冷轧': '1850',
    '1850车间': '1850',
    '2050冷轧': '2050',
    '2050车间': '2050',
    '铸轧分厂': 'cast_rolling',
    '铸锭车间': 'casting',
    '热轧车间': 'hot_rolling',
    '退火分厂': 'annealing',
    '精整分厂': 'finishing',
}

_SOURCE_PRIORITY = ['dingtalk_specialist', 'mes', 'wms', 'datahub', 'historical_report', 'rag']


def normalize_factory_request(text: str, intent: FactoryBrainIntent) -> FactoryBrainNormalizedRequest:
    clean = str(text or '').strip()
    org_units = _normalize_org_units(clean, intent)
    metrics = _normalize_metrics(clean, intent)
    needs_artifact = intent.domain == 'artifact' or any(token in clean for token in ('表格', '文档', 'PDF', '图表', '图片'))
    output_mode = 'artifact' if needs_artifact else _normalize_output_mode(clean)
    return FactoryBrainNormalizedRequest(
        intent=intent,
        normalized_text=clean,
        business_date=intent.business_date,
        scope='workshop' if org_units != ['factory'] else 'factory',
        org_units=org_units,
        metrics=metrics,
        data_sources=list(_SOURCE_PRIORITY),
        output_mode=output_mode,
        needs_artifact=needs_artifact,
    )


def _normalize_org_units(text: str, intent: FactoryBrainIntent) -> list[str]:
    values = []
    raw_workshop = str((intent.entities or {}).get('workshop') or '').strip()
    if raw_workshop in _WORKSHOP_ALIASES:
        values.append(_WORKSHOP_ALIASES[raw_workshop])
    for alias, canonical in _WORKSHOP_ALIASES.items():
        if alias in text and canonical not in values:
            values.append(canonical)
    return values or ['factory']


def _normalize_metrics(text: str, intent: FactoryBrainIntent) -> list[str]:
    task = intent.task_type
    if task in {'daily_output', 'daily_report'} or '产量' in text:
        return ['daily_output', 'monthly_output']
    if task == 'factory_overview':
        return ['daily_output', 'inventory', 'contract_balance', 'yield_rate', 'energy_cost', 'anomaly']
    if task == 'inventory_query':
        return ['inventory', 'inbound_finished_goods']
    if task == 'contract_balance':
        return ['contract_balance']
    if task == 'energy_analysis':
        return ['electricity', 'gas', 'unit_consumption']
    if task == 'cost_analysis':
        return ['electricity_cost', 'gas_cost', 'unit_cost']
    if task == 'artifact_request':
        return ['daily_output']
    return [task]


def _normalize_output_mode(text: str) -> str:
    if any(token in text for token in ('日报', '月报', '年报', '正式')):
        return 'formal_report'
    if any(token in text for token in ('分析', '怎么看', '哪里不对劲')):
        return 'analysis'
    return 'short_answer'
```

def describe_evidence_gap(
    normalized: FactoryBrainNormalizedRequest,
    references: list[FactoryBrainDataReference],

from __future__ import annotations


def classify_feedback_learning(feedback_text: str, *, is_root_owner: bool) -> dict[str, str]:
    clean = str(feedback_text or '').strip()
    if any(token in clean for token in ('Codex', '改', '新增接口', 'SQL', '补测试')):
        if not is_root_owner:
            return {
                'learning_type': 'construction_request',
                'status': 'denied',
                'reason': '只有 root_owner 可以提交施工任务',
            }
        return {
            'learning_type': 'construction_request',
            'status': 'needs_codex',
            'reason': '涉及系统施工',
        }
    if any(token in clean for token in ('口径', '按同一', '归一', '车间', '指标')):
        return {
            'learning_type': 'candidate_knowledge',
            'status': 'needs_verification',
            'reason': '涉及业务口径或数据映射',
        }
    return {
        'learning_type': 'auto_memory',
        'status': 'accepted',
        'reason': '低风险表达偏好',

def _json_safe(value: Any) -> Any:
    if hasattr(value, 'isoformat'):
        return value.isoformat()
    if isinstance(value, dict):
        return {str(key): _json_safe(item) for key, item in value.items()}
    if isinstance(value, list):
        return [_json_safe(item) for item in value]
    return value
```
