## 用户原话（2026-11-10）

「3d建模太粗糙了，再加些真实厂房的细节和一些科技图形UI元素，系统整体看着太单调。」

## 现状（11/10 正式地址 7101b287 实查）

- **3D 工厂**（`/manage/factory-3d`，`src/components/factory/factory-scene.js`）：每个车间是一个纯色长方体，高度=当天吨数；地面是一块灰板；没有屋顶、墙面、道路、大门、厂区边界、非生产建筑细节。没数据的车间是灰色薄板，几乎看不出是厂房。
- **3D 产线**（实时页 `LiveProcessFlow.vue`）：6 个同样的长方体排成一行，看不出铸轧机、轧机、退火炉、卷材。
- **整体页面**：白纸品牌蓝方向（11/08 用户确认）。总览页顶部有大块空白，趋势只有一条灰线，卡片全白、层次弱；页面最大宽 1440，在 2552 宽屏上两侧大量留白。
- 已有可复用：`XtWorkshopGlyph`（细线工序图标）、`XtRollingLine`（登录页轧机线条画）、`AnimatedMetricValue`（数值滚动）、`XtEmpty`（细线铝卷）、设计 token（`src/design/xt-tokens.css`）。
- 真实素材：新厂平面图（已转写：北排长厂房、西/中/东三区、南侧两门、停车位、宿舍、办公、监控室、仓库、调度室）；公司介绍 PDF 照片（蓝色彩钢屋顶长厂房、采光带、行车、成卷铝材）。

## 方向（11/10 用户重新决定）

- **D1：全系统换暗色科技主题**（推翻 11/08「白纸品牌蓝」）。品牌蓝仍是主色，在暗底上提亮使用。
- **D2：3D 厂房固定外形，屋顶上加数据柱表示吨数**，没数据不画柱、标「—」。
- 不变的规矩：图形只用真实数据，缺数显示缺；进入时一次性动画加少量循环；遵守减少动态效果；不写解释文案。

## 现有可复用的暗色基础（11/10 实查）

- `src/design/xt-hud.css`（116 行）：`:root[data-xt-theme="hud"]` 下有一套暗色变量（`--xt-hud-canvas #04101f`、面板、边框、文字、主色 `#5eb8ff` 等），只覆盖了外框（左栏、顶栏、`.panel`、数字、登录页局部）。
- `useHudTheme.js`：按浏览器本地偏好或用户偏好（后端 `user_preferences.theme`）给 `<html>` 加 `data-xt-theme="hud"`；`ManageShell` 已调用；`useHudChartTheme.js` 会跟着切换 ECharts 配色。
- 缺口：页面组件里有 227 处写死颜色（54 个文件，工程评审实查）；Element Plus 组件（表格、下拉、弹窗、日期）没有暗色变量；登录页端到端测试锁定「不是 hud」。

## 计划

### W1 3D 工厂：真实厂房

- 厂房外形固定，不再用高度表示吨数：彩钢墙面（浅灰）+ 双坡屋顶（品牌蓝系彩钢色，参考公司照片）+ 屋脊采光带 + 墙面窗带细线。
- 吨数改用每个车间屋顶上方的一根数据柱（品牌蓝，按工序分组缩放），没数据不画柱，屋顶上标「—」。
- 厂区：围墙线、主干道和车道线、南侧西门/东门、停车位、宿舍/人力资源科/办公楼/监控室/仓库/调度室（平面图上有的才画），少量树。
- 交互：悬停车间高亮描边并显示该车间名和吨数，点击仍进车间看板。
- 光照：柔和平行光 + 软阴影（只算一次，静态场景按需渲染不变）。
- 性能：几何合并（同材质 InstancedMesh / mergeGeometries），绘制调用控制在 60 以内；仍按需渲染。

### W2 3D 产线：设备造型

- 每道工序换成可辨认的简化设备：铸轧（熔炉+铸轧辊）、热轧/冷轧（机架+上下轧辊）、退火（炉体）、精整（剪切机台）、包装入库（成卷铝材堆）。
- 工序间用传送辊道连接；有产量的工序之间有一个铝卷沿辊道移动的循环动画（仅页面可见、未开减少动效时运行，限 30fps，标签页隐藏即停）。
- 数据：设备旁的数据柱高度=实时吨数，缺数不画柱。

### W3 全系统暗色科技主题

- **做法**：不另起一套 `--xt-hud-*`，而是在 `data-xt-theme="hud"` 下直接重定义核心 `--xt-*` token（底色、面板、边框、文字、主色、状态色），让所有用 token 的页面自动变暗；`xt-hud.css` 里的外框规则并入。
- **默认开启**：所有人默认暗色；保留后端用户偏好字段，以后需要时可加回浅色切换（本次不做切换入口）。
- **Element Plus**：引入其官方暗色变量并映射到我们的 token（表格、表单、下拉、弹窗、日期、分页、标签）。
- **写死颜色清理**：54 个文件 227 处改为 token；按页面分批，每批截图核对对比度（正文 ≥ 4.5:1）。
- **登录页**：暗底 + 公司铝卷照片加暗色遮罩，测试改为「是暗色」。
- **ECharts**：走现有 `useHudChartTheme`，补齐网格线、坐标轴、提示框颜色。
- **3D**：地面深色、厂房浅灰亮面、屋顶品牌蓝、数据柱亮蓝，和暗色主题一致。

### W4 科技图形 UI 元素（暗底细线）

一组可复用的小组件，全部走 token，不用霓虹发光、粒子、扫描线：

- `XtTechFrame`：关键区块四角细线角标 + 可选坐标刻度（总览主图、实时调度墙、3D 舞台）。
- 网格底纹：3D 舞台和主图区背景用极淡网格（CSS 背景，零请求）。
- `XtPulseDot`：实时连接/数据新鲜度的呼吸点（只在实时数据时动）。
- `XtRing`：环形进度（成品率、填报率、计划完成率），只接真实比例。
- KPI 数字下方迷你走势（复用现有数据，缺数不画）。
- 总览顶部空白区改放主图（产量走势加面积渐变和日期刻度）。

应用范围：总览、实时、生产、异常 4 个主页面的头部和 KPI 区；3D 两个舞台。

### 不做

- 霓虹发光、粒子、扫描线等纯装饰效果。
- 浅色/暗色切换入口（保留偏好字段，本次只做暗色）。
- 真实 BIM/精确尺寸建模（没有图纸尺寸）。
- 老厂 3D。
- 新数据接口。

## 验收

- 截图对比：3D 工厂能认出是带屋顶的厂房和厂区道路大门；产线能认出轧机/炉子/卷材。
- 性能：3D 工厂绘制调用 ≤ 60，首帧 < 1s（本机）；静止时 CPU 无持续占用；产线动画标签页隐藏即停。
- three 分块 gzip 仍 ≤ 180KB；非 3D 页面首屏 JS 增量 ≤ 5KB gzip。
- 单测锁定：缺数不画柱/不画 0、数据柱按工序分组缩放、科技组件不接假数据。
- 端到端：两种 3D 视图、2D 兜底、减少动效时无循环动画。

## 阶段 1：策略评审（SELECTIVE EXPANSION，Claude 子代理；Codex 本机不可用）

### 前提确认（用户 11/10）
- D1 全系统暗色科技主题；D2 厂房固定外形 + 屋顶数据柱。

### 子代理结论（8 条）
1. critical：「全系统」是否含 /entry 手机填报没写清；现场强光下暗底难看清，误填伤日报主链。→ 交用户最终确认（可用性风险）。
2. high：暗色一次性默认开启风险大（漏改页面会白底白字）。→ 保留 localStorage 应急回浅色开关（无界面入口）；打印页和 `@media print` 强制浅色。
3. high：顺序反了，用户最先感到单调的是总览。→ 批次 1 先做暗色外框 + 总览/实时 + 科技组件。
4. high：产线铝卷循环动画投入产出低。→ 延后；设备造型保留（用户原话要求建模细节）。
5. medium：厂区细节易膨胀。→ 第一批只做厂房外形、屋顶、采光带、数据柱、悬停、围墙、主路、两门；附属建筑扁平块加名称；数据柱直接标吨数。
6. medium：项目基线把视觉排在最后，日报还有 90 条缺口。→ 不碰数据接口和填报链路。
7. medium：深浅 token 会分叉、新页面又写死颜色。→ 加单测/lint 禁止 .vue 新增 #hex/rgba；厂区布局继续数据驱动。
8. medium：退路方案「只在大屏类页面暗色」。→ 只作第 2 条的退路，不推翻 D1。

### 批次顺序（采纳）
1. 暗色 token + 外框 + 登录页 + 总览/实时科技组件（主图、角标、XtRing、迷你走势、XtPulseDot）；打印页强制浅色；应急开关。
2. 3D 工厂真实厂房（W1 第一阶段）。
3. Element Plus 暗色映射 + 逐页清理写死颜色（生产、异常先）+ 禁止写死颜色的测试。
4. 3D 产线设备造型（无循环动画）。
5. 可选：附属建筑细节、铝卷循环动画。

### NOT in scope
霓虹/粒子/扫描线；浅色切换界面入口；老厂 3D；BIM 精确尺寸；新接口；填报链路改动。

### What already exists

### 发现（全部采纳）
1. high：主题靠组件挂载/卸载控制，已漏到 /entry（后端偏好 hud 时 /entry 也变暗），登出又把登录页变浅。→ `router.afterEach` 按路由统一决定：/manage、/login 暗色，其余浅色；`writeHudPreference` 只存不改 DOM；删 ManageShell 卸载清理。
2. high：首帧闪白。→ index.html head 内联脚本按路径设主题 + `html{background:#060d18;color-scheme:dark}`。
3. high：EP 暗色。→ 同时切 `html.dark`，main.js 引官方 dark css-vars（纯 CSS），`:root[data-xt-theme="hud"]` 下把 `--el-*` 映射到 token；/entry 不加类。
4. high：打印白纸浅字（QRCodePrint 背景写死 #fff、字用 token）。→ `@media print` 下 hud 还原浅色 token，单测锁定。
