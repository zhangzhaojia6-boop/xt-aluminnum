# 2026-06-12 前端 image2 + Stitch + MES 主数据执行验收记录

## 本轮目标

把管理端与手机端继续向 image2 和 Stitch 的工业蓝视觉颗粒度靠齐，同时确认前端核心页面以 MES 投影数据为主、人工填报为补录和对照、算法数据为计算层，并统一到十二个活跃车间口径。

十二个活跃车间为：铸锭、铸二、铸三、热轧、精整、拉矫、园区剪切、新厂在线、园区在线、冷轧1650、冷轧1850、冷轧2050。

## 已完成的关键动作

1. 新增并使用活跃车间标准化工具，前端日报、调度、填报明细等页面只展示十二个活跃车间。
2. 管理端关键页面加入数据来源分层表达，区分 MES 外部数据、人工填报、算法数据。
3. 管理端设置页补齐十二车间、别名映射、机列台账、PC 工艺映射、数据源状态等入口语义。
4. 手机端填报页修复质量问题开关被底部操作区遮挡的问题，避免现场人员点不到开关。
5. 保持接口兼容，没有删除旧接口，没有改生产数据。
