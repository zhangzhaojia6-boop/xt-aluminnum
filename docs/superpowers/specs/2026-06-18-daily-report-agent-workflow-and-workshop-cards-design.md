# 2026-06-18 日报秘书 Agent、RAG 知识库与车间分项日报卡设计

## 1. 目标

把“鑫泰铝业 数据中枢”的日报、钉钉 Agent、RAG 知识库和 MES SQL Server 数据对接整理成一套可执行规则。

最终效果：

- 每天早上 7:30 自动发送全厂日报初版。
- 每天早上 9:35 根据人工补录统一重算，必要时发送补录修正版。
- 全厂日报每天都带所有车间分项日报卡。
- 所有车间分项按“车间 -> 机列/产线 -> 工艺路线/工序 -> 指标”分类。
- MES 数据作为主数据，人工填报作为补录、纠偏、异常说明。
- RAG 只保存模板、字段解释、工艺规则、系统数据字典，不保存每天动态数字。
- 所有钉钉外发都必须走 `agent_outbox` 和 `external_message_logs`，不能绕过系统直接发。

## 2. 当前系统现状

云端已经存在 6 个张兆嘉范围的 Agent：

- `factory_dispatch_zzj`：全厂调度 Agent。
- `fill_gap_guard_zzj`：填报对账 Agent。
- `energy_guard_zzj`：能耗守卫 Agent。
- `quality_guard_zzj`：质量异常 Agent。
- `daily_report_secretary_zzj`：日报秘书 Agent。
- `governance_auditor_zzj`：治理留档 Agent。

现状判断：

- 6 个 Agent 已经有名称、类型、能力标签和钉钉通道绑定。
- 6 个钉钉自定义机器人通道已经创建，并切到正式发送。
- 数据库通道只保存环境变量引用名，不保存 webhook 或 secret 明文。
- 云端 RAG 当前为空库，尚未导入知识文档。
- 系统已有输出 skill 日报正文解析器和模板日报生成器。
- 系统已有 `agent_outbox`、`external_message_logs`、Agent 管理页、通讯通道页。

不足：

- 6 个 Agent 还没有完整 SOP 工作流。
- 日报秘书还没有固定 7:30 初版、9:35 修正版的自动发布闭环。
- RAG 还没有导入 D:\输出skill 模板和数据字典。
- 车间分项日报卡还没有统一配置模型。

## 3. 六个 Agent 的职责边界

### 3.1 全厂调度 Agent

职责：

- 每天读取全厂生产状态。
- 监控 MES 同步状态。
- 汇总产量、在制料、异常、缺报。
- 对生产大屏和日报口径做主动说明。

触发：

- 每天 7:30 跟随日报初版发送全厂总览。
- 实时发现重大异常时可写入 outbox，按配置发送。

不能做：

- 不能修改生产数据。
- 不能直接改日报正文。

### 3.2 填报对账 Agent

职责：

- 检查 MES 数据和人工补录之间的差异。
- 检查缺报、未匹配机列、未匹配工艺、填报无产量、产量无填报。
- 在 9:35 修正版前输出差异摘要。

触发：

- 每天 7:30 前检查初版缺口。
- 每天 9:35 前检查补录变化。
- 发现关键字段变化时给日报秘书提供变化摘要。

不能做：

- 不能为了提高匹配率修改原始 MES 数据。
- 不能静默覆盖人工补录。

### 3.3 能耗守卫 Agent

职责：

- 检查电、气、水、吨耗、成本。
- 今日吨耗、月吨耗按对应车间的包装产量作为分母。
- 发现能耗数据缺失或吨耗异常时输出原因。

触发：

- 每天 7:30 初版日报取当时已有数据。
- 每天 9:35 修正版重算补录后的吨耗。
- 能耗为 0、包装产量为 0、吨耗异常时提醒。

不能做：

- 不能凭空估算能耗。
- 不能把未接入的物联网数据当作真实数据。

### 3.4 质量异常 Agent

职责：

- 汇总质量异常、门禁阻断、现场问题。
- 给日报秘书提供质量段落和异常清单。
- 发现阻断项时标记日报质量风险。

触发：

- 每天 7:30 生成初版质量摘要。
- 每天 9:35 重新检查是否有补录质量问题。

不能做：

- 不能自动关闭质量异常。
- 不能隐藏阻断项。

### 3.5 日报秘书 Agent

职责：

- 每天 7:30 生成并发送全厂日报初版。
- 每天 9:35 重算日报。
- 如果关键字段发生变化，发送补录修正版。
- 每天都附带所有车间分项日报卡。
- 生成变化摘要。
- 把每次发送写入 outbox 和 external_message_logs。

触发：

- 7:30 自动发送初版。
- 9:35 自动判断是否发送修正版。
- 指定人员确认后标记最终定稿版。

不能做：

- 不能绕过审批发布最终定稿。
- 不能把 RAG 中的历史数字当作今日真实数字。
- 不能绕过 outbox 直接调用钉钉。

### 3.6 治理留档 Agent

职责：

- 审计 Agent 外发、审批、补录、日报版本变化。
- 保留初版、修正版、最终版的差异记录。
- 检查是否存在未授权发送或直接绕过 outbox 的发送。

触发：

- 每天日报流程结束后生成治理摘要。
- 发现失败发送、死信、重复发送时提醒。

不能做：

- 不能删除历史发送记录。
- 不能改写审计日志。

## 4. RAG 知识库设计

### 4.1 可以进入 RAG 的内容

- D:\输出skill 最近日报正文。
- D:\输出skill 最近核对记录。
- 日报模板说明。
- 车间分项日报卡模板。
- MES SQL Server 表结构说明。
- 系统数据字典。
- 页面字段映射说明。
- 业务时间口径。
- 工艺路线、机列、PC、设备别名规则。
- Agent SOP 和审批规则。

### 4.2 不进入 RAG 的内容

- 数据库密码。
- 钉钉 webhook。
- 钉钉 secret。
- LLM API key。
- 每天动态产量明细原始表。
- 每天动态能耗原始表。
- 任何真实密钥、token、连接串。

原因：

- RAG 是用来查规则和解释的，不适合保存每天变化的数字。
- 每天数字必须实时查数据库，避免回答过期数据。

### 4.3 RAG 文档分类

建议分类：

- `daily_report_rule`：日报格式、段落顺序、输出 skill 模板。
- `workshop_card_rule`：各车间分项日报卡规则。
- `mes_field_rule`：MES 字段解释。
- `system_field_rule`：数据中枢字段解释。
- `time_rule`：7:30、9:35、业务日、跨日规则。
- `mapping_rule`：MES 字段到系统字段的映射。
- `approval_rule`：谁能确认、谁能发布、谁能补录。
- `agent_workflow_rule`：6 个 Agent 工作流。

## 5. MES SQL Server 和系统数据字典

MES SQL Server 只能只读使用。

目标不是把 MES 原始数据全部放进 RAG，而是生成两类资料：

### 5.1 MES 数据字典

内容包括：

- 表名。
- 字段名。
- 字段类型。
- 中文含义。
- 单位。
- 时间字段。
- 车间字段。
- 设备字段。
- 工艺字段。
- 卷号字段。
- 重量字段。
- 能否用于日报。

### 5.2 业务映射字典

内容包括：

- MES 字段。
- 数据中枢字段。
- 前端页面字段。
- Agent 可用事实。
- 单位换算。
- 时间窗口。
- 缺失时显示规则。

示例：

```text
MES字段：下机重量
单位：kg
系统字段：output_weight_tons
换算：kg / 1000 = 吨
用于页面：生产大屏、昨日日报、生产分析
用于Agent：全厂调度、日报秘书、填报对账
缺失显示：/
```

## 6. 日报发送版本规则

### 6.1 7:30 初版

每天早上 7:30 自动发送。

数据来源：

- MES 已同步数据。
- 系统已有填报数据。
- 已经存在的能耗、质量、合同、在制料数据。

标题：

```text
鑫泰铝业 数据中枢
6月17日生产日报（7:30初版）
```

规则：

- 初版必须发送。
- 缺失字段显示 `/`。
- 缺失字段写入异常与缺口。
- 初版入库归档。

### 6.2 9:35 补录修正版

每天早上 9:35 固定统一重算。

发送条件：

- 关键字段发生变化才发送。
- 没有变化则不重复发送。

关键字段包括：

- 全厂产量。
- 各车间产量。
- 包装产量。
- 入库产量。
- 在制料。
- 能耗。
- 今日吨耗。
- 月吨耗。
- 成品率。
- 合同量。
- 质量异常。

修正版标题：

```text
鑫泰铝业 数据中枢
6月17日生产日报（补录修正版）
```

变化摘要示例：

```text
【补录修正】
园区剪切 包装：175.421 -> 182.300
园区剪切 今日吨耗：14.88 -> 14.32
原因：人工补录包装产量
```

### 6.3 最终定稿版

指定人员确认后形成最终定稿。

规则：

- 最终定稿只改状态，不删除初版和修正版。
- 最终定稿必须保留确认人、确认时间、版本号。
- 后续如果再补录，只能形成新的修订记录。

## 7. 车间分项日报卡体系

所有车间每天都要随全厂日报一起发。

统一结构：

```text
【车间名称】
日期
字段1 数值
字段2 数值
字段3 数值
异常 /
```

字段来源优先级：

1. MES SQL Server 主数据。
2. 数据中枢算法计算。
3. 人工补录。
4. 缺失显示 `/`。

### 7.1 园区剪切车间卡片

模板：

```text
园区剪切车间
6月16日
飞剪下机74.17
重卷下机12.685
包装175.421
外加工/
入库产量103.809
退火板63.183
合计166.992
今日吨耗14.88
月吨耗15.59
```

口径：

- 今日吨耗分母：当日包装产量。
- 月吨耗分母：当月累计包装产量。
- 合计：入库产量 + 退火板。
- 包装产量优先 MES 包装工序。
- 缺失字段显示 `/`。

### 7.2 其他车间卡片

每个车间按机列和工艺路线分类。

活跃车间至少包括：

- 铸锭。
- 铸二。
- 铸三。
- 热轧。
- 淬火。
- 冷轧1650。
- 冷轧1850。
- 冷轧2050。
- 新厂在线。
- 园区在线。
- 拉矫。
- 精整。
- 园区剪切。
- 回收。
- 大修。

如果某些车间不参与产量口径，只作为专项，也仍然生成分项卡。

## 8. 车间、机列、工艺路线配置模型

建议建立三层规则：

### 8.1 车间规则

定义：

- 车间名称。
- 是否生成日报卡。
- 是否计入全厂产量。
- 是否需要能耗吨耗。
- 是否需要人工补录。

### 8.2 机列工艺映射

定义：

- MES PC 名称。
- MES 设备名。
- 数据中枢机列名。
- 所属车间。
- 工艺路线。
- 当前工序。
- 是否参与包装产量。

### 8.3 日报字段规则

定义：

- 字段名称。
- 字段来源。
- 计算公式。
- 单位。
- 小数位。
- 缺失显示。
- 是否关键字段。

## 9. 数据流

7:30 初版数据流：

```text
MES SQL Server
  -> 数据中枢同步表
  -> 车间/机列/工艺映射
  -> 日报事实收集器
  -> 全厂日报正文
  -> 车间分项日报卡
  -> agent_outbox
  -> 钉钉日报秘书机器人
  -> external_message_logs
```

9:35 修正版数据流：

```text
人工补录
  -> 数据中枢补录表
  -> 日报事实重算
  -> 与 7:30 初版做差异对比
  -> 有关键变化则生成补录修正版
  -> agent_outbox
  -> 钉钉日报秘书机器人
  -> external_message_logs
```

## 10. 权限和安全

规则：

- MES SQL Server 只读。
- 不写 MES 原库。
- 不把数据库账号密码写入 Git。
- 不把密钥写入 RAG。
- 不把密钥写入前端包。
- 不把密钥写入 migration、fixture、测试日志。
- 日报正式定稿必须指定人员确认。
- Agent 不能绕过 outbox 直接发送钉钉。

## 11. 异常处理

字段缺失：

- 显示 `/`。
- 写入异常与缺口。
- 不阻断 7:30 初版发送。

MES 未同步：

- 7:30 初版照常发送。
- 数据来源标记为缺失。
- 9:35 如果同步恢复并产生关键变化，则发修正版。

人工补录冲突：

- 不静默覆盖。
- 显示 MES 值、补录值、最终采用值。
- 变化写入补录修正摘要。

钉钉发送失败：

- outbox 标记 retrying。
- 最多重试 3 次。
- 超过后 dead-letter。
- 治理留档 Agent 发送失败摘要。

## 12. 测试验收

必须覆盖：

- 6 个 Agent 身份和通道绑定。
- RAG 上传 D:\输出skill 日报正文和核对记录。
- RAG 拒绝密钥文本。
- MES 字典生成时不泄露数据库密码。
- 7:30 初版一定生成。
- 9:35 无变化不重复发。
- 9:35 有变化发送修正版。
- 园区剪切今日吨耗按包装产量计算。
- 所有车间都生成分项卡。
- 缺失字段显示 `/`。
- outbox 和 external_message_logs 留档。
- 钉钉机器人真实发送只走 outbox。

## 13. 不做的事

本设计不做：

- 不训练或微调大模型。
- 不删除旧入口。
- 不重写系统。
- 不把 MES 原始动态数据塞进 RAG。
- 不让前端直连 MES SQL Server。
- 不绕过审批自动定稿。

## 14. 推荐实施顺序

1. 先补全 6 个 Agent 的 SOP 配置。
2. 生成并导入 RAG 基础知识：输出 skill 模板、核对记录、数据字典、Agent 工作流。
3. 只读扫描 MES SQL Server 表结构，生成 MES 字典。
4. 建立车间、机列、工艺路线、日报字段规则。
5. 实现车间分项日报卡事实收集和渲染。
6. 接入 7:30 初版定时任务。
7. 接入 9:35 修正版定时任务。
8. 接入补录差异摘要。
9. 做浏览器、后端、钉钉真实发送全链路验收。
