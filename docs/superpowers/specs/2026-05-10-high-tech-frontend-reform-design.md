# 全量前端改革设计：硬核深空数据舱 (High-Tech Data Center)

Date: 2026-05-10  
Status: 待审阅  
适用系统: 鑫泰铝业 数据中枢  

## 1. 背景与目标

当前的数据中枢前端使用了标准的 Vue 3 + Element Plus，视觉表现偏向传统的后台管理系统。本次全量前端改革的目标是进行“美学降维打击”，将普通后台升级为**好莱坞科幻级（Palantir/贾维斯风格）的顶级战术工业控制台**。

**核心目标：**
1. 重塑“数据中枢”第一印象，使其具备压倒性的科技力量感。
2. 引入 3D、高能粒子流和严密的切角 UI（Sci-Fi HUD），彻底消除 Element Plus 的“廉价感”。
3. 保证现有业务逻辑（图表、数据接口、权限边界）零破坏，仅对渲染层和交互外壳进行全面换血。

## 2. 技术栈演进 (The Arsenal)

为支撑极致硬核的科技美学，前端基础架构需做如下增强：
- **核心框架**：保留 Vue 3 + Vite。
- **UI 引擎扩充**：引入 **Tailwind CSS**（处理基于网格的高密度排版与原子化发光控制）。
- **3D 与粒子动效**：引入 **Three.js** 配合 `@vue-three/core` (或原生 Three.js) 渲染登录页的三维全厂数字孪生网格。
- **序列化过场与微交互**：引入 **GSAP**（GreenSock）取代原生 CSS 过渡，实现进场、数据解码（Scramble Text）和复杂轨迹动画。
- **基础组件**：通过深度的全局 SCSS/CSS 劫持，将 Element Plus 的基础组件从白底/圆角改造为切角/玻璃质感。

## 3. 核心改革模块设计

### 3.1 模块一：Quantum Portal (原 Login.vue)
- **视觉主轴**：抛弃左右分栏。背景是一个占据全屏的深色 3D 铝工业拓扑网格（基于 Three.js 的粒子点阵）。网格会随鼠标轻微转动（Parallax Effect）。
- **表单面板**：终端机悬浮视窗（Terminal Window）。无实体边界框，只有角落的高亮 L 型准星（Reticle）和 45 度切角。
- **交互逻辑**：输入框获取焦点时，呈现机械光标闪烁；点击“进入中枢”触发 GSAP 序列动画，背景 3D 网格瞬间产生类似星际跃迁的放射状粒子加速效果，全屏变白/高亮后渐隐切入主后台。

### 3.2 模块二：战术指挥控制台 (ManageShell 2.0)
- **HUD 布局重构**：
  - **侧边栏**：不再是纯色区块，而是由超细的蓝色发光线勾勒边界。导航项使用机械感等宽字体，高亮态时伴有数据碎片化的进入动效（Scramble）。
  - **顶部状态带**：取消常规模包屑，改为持续流动的“数据接入流（Data Stream）”指示器，加上类似雷达扫描的微动效。
- **视觉 Token 重定义**：
  - **背景**：绝世的黑 `#00050B` 至 `#020F20` 的极夜蓝渐变。
  - **组件边界**：移除所有的 `1px solid gray`，全部换为带有 CSS 混合模式（Mix-Blend-Mode）的荧光蓝或警戒橙半透明边界。
  - **数据排版**：全量替换业务核心数字的字体栈，首选 `JetBrains Mono` 或 `Orbitron`，配合字间距缩紧（Tracking -0.05em），带来极致的工程严谨度。

### 3.3 模块三：组件“全息化”改造 (Element Plus Override)
- **表单与下拉 (Input/Select)**：深黑色半透底色，聚焦时边框发亮并伴有轻微的底光（Box-Shadow Glow）。
- **弹窗 (Dialog/Drawer)**：废弃传统投影，改用极高强度的亚克力模糊（`backdrop-filter: blur(40px)`）结合浅蓝色霓虹边框。
- **图表 (Echarts)**：禁用默认配色。将图表强行注入“黑底+荧光线”主题（Cyberpunk Theme），轴线变暗，数据线加宽并辅以 `shadowBlur` 发光效果。

## 4. 非目标 (Out of Scope)
- 不改变现存路由定义与后端数据接口。
- 不引入类似 React 的异构前端框架。
- 不在一期深入重绘每一个表单的内容项（优先解决外壳和高频组件，让内部页面通过 CSS 继承自动暗黑化）。

## 5. 风险与未知 (Risks & Unknowns)
- **性能评估**：Three.js 3D 粒子和大量的 `backdrop-filter` 可能会在低配核显机型上掉帧。
  - *应对方案*：监测 `window.requestAnimationFrame` FPS，若持续低于 30，则优雅降级为静态 SVG 网格图片+ CSS 渐变。
- **Echarts 层叠冲突**：复杂的高斯模糊图层可能会和 Echarts 的 Canvas 渲染层发生 Z-Index 或重绘穿透问题。
  - *应对方案*：锁定所有 Echarts 的 `z-index` 层级并在父容器限制 `transform: translateZ(0)` 强制 GPU 合成隔离。
