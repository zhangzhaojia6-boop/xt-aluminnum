# 物资采购模块设计记录

依据：`物资采购管理办法.docx`（定稿，16 个环节）和 `物资采购全流程线上化实施方案.docx`。`修订稿` 是没有法务审查的早期 14 步版本，未采用。

## 范围

- 16 个环节全线上走单：提报、车间审批、技术审核、库存核查、比价、比价确认、豁免审批、采购审批、拟合同、法务、财务、签订、进厂、验收、质检、单据收集、付款审核、付款审批、付款入账。
- 紧急采购：先到货，三个工作日内补比价和合同；超限额要总经理同意。
- 付款前校验九类单据和发票、合同、付款金额，疑似拆单只提醒不拦截。
- 库存够用时直接结束，由车间领用；不够时只买差额。

## 关键决定

| 决定 | 原因 |
|---|---|
| 审批在系统内办理，钉钉免登打开 | 钉钉原生 OA 审批需要管理员建模板和开权限，尚未具备 |
| `PROCUREMENT_ENABLED` 默认关闭，接口返回 404 | 办理人和管理层批准都未落实前不能让人走单 |
| 办理人由管理员按岗位指派，管理员本身不能审批 | 岗位分离 |
| 每单一种物料 | 多行明细要先和业务确认比价和合同如何拆 |
| 库存由仓库手填 | 备品备件系统的接口情况未知 |

## 下一阶段

通知和超时催办（走 dry-run 发件箱）、智能体对话提报和查进度、标准合同模板、供应商评价、分批到货。智能体不审批，不改金额。

## 上线步骤

1. 备份后执行 `alembic upgrade head`（`0058_procurement`，部署脚本不跑迁移）。
2. 设 `PROCUREMENT_ENABLED=true`，管理员在 `/procurement/board` 指派办理人。
3. 试点一张真实单据走完 16 环节，再开放全员。
