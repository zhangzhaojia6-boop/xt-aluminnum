# 管理端老板视角骨架重构 · 设计文档

**日期**：2026-05-21
**作者**：xt（讨论） / Claude（成文）
**状态**：待用户复核
**范围**：管理端骨架（仅老板/厂长一类用户）

---

## 1. 背景

管理端目前承载 30+ 路由、14 个"中心"，导航元数据、路由表、`adminNavigation` / `reviewNavigation` / `centerNavigation` 三套数字互不一致。同名概念有多个入口（"工厂"相关 9 页、异常 4 处入口、"经营"两套）。多个页面挂在 router 上但未挂入任何菜单，用户只能凭收藏夹或旧链接进入。

骨架按 IT 视角组织（接入 / 治理 / 模板 / 运维 / 编号 01-14），不按使用者关心的问题组织。

## 2. 范围

**本轮只重构老板/厂长一类用户的视图。**

- 在管理端 5 类潜在用户（老板/厂长、车间主任、质检、财务、IT）中，本轮只动老板/厂长。
- 操作端（10+ 页工人填报）本轮不动，列入下一轮。
- 编辑者（总统计）工作台本轮不动，列入下一轮（任务 #9）。
- 其余 4 类管理端用户的视图、权限、入口本轮不变。

## 3. 老板视角的 4 类问题

老板每天打开系统，脑子里只有 4 类问题——确认结论："4 类都要"：

1. 昨天产了多少（产量）
2. 赚不赚钱（经营估算）
3. 今天什么事（异常）
4. 某件具体事（追踪：某客户/某订单到哪了）

设备：手机+电脑各一半。**一套响应式代码，不分两套实现。**

## 4. 顶层骨架：3 tab + 顶部搜索 + 齿轮抽屉

| tab | 路由 | 解决的问题 | 默认进入 |
|---|---|---|---|
| 今日 | `/today` | 一屏看全厂当下情况 | ✅ |
| 生产 | `/production` | 钻进车间/机台/卷查产量与达成 | |
| 异常 | `/alerts` | 今天有几件事、哪件最要紧 | |

**顶部全局搜索**（Cmd+K / 移动端搜索图标）→ 覆盖"追踪"问题。任意 tab 内可用。搜订单号、客户名、卷号、设备编号。低频，不占顶层 tab。

**右上角齿轮 → 设置抽屉**：装 admin 杂物（接入 / 主数据 / 模板 / 规则 / 用户 / 治理 / 运维 / 系统 / AI / 杂项）。老板平时看不见。

**手机版**：底部 3 个 tab，搜索在顶部，齿轮在"今日"右上角。
**电脑版**：左侧 3 个一级导航，顶部全局搜索条，齿轮右上角。同一套 Vue 组件，按宽度切布局。

## 5. 各 tab 内部结构

### 5.1 今日 tab（默认页）

老板进系统第一屏。一眼看到全厂当下情况。

**首屏布局（自上而下）**：

1. **5 秒概览条**：5 个核心数字一排
   - 日产量 / 比昨日 / 达成率 / 日吨成本 / 月累产量
2. **车间分布条形图**：14+ 车间今日产量+月累，按真实层级横向对比
3. **要紧事 top 3**：从异常 tab 取严重度 top 3 卡片，可点击跳转
4. **今日成本一行**：电费 / 气费 / 合计，可展开
5. **完整日报正文（折叠）**：默认折起。展开 = 现在钉钉里收到的 5 段中文 prose（来自 to boss.md 格式）
6. **附件区**：当日各车间 Excel + 微信图片，一键下载/转发钉钉

**关键约束**：
- 顶部 5 个数字与 prose 中数字逐字一致。任意数字可点 → 跳生产 tab 当天对应车间详情，作为"信任锚点"。
- 历史用日期切换（昨日 / 前日 / 上周）。月底那天的"今日"屏自带当月汇总段，**不做独立"月报 tab"**。
- 不做"自定义报表"。本轮老板只读。

### 5.2 生产 tab

老板每天 80% 时间在这。

**首屏 = 厂级今日卡片**，三层信息密度（厂总 → 班次 → 车间）：

1. 厂级数字（已产 / 达成 / 估算毛利 / 同比 / 缺口 / 能耗）
2. 班次进度条（夜班/早班/晚班，当前班次高亮）
3. 车间排名（按达成，拖后的橙色标记）

**下钻 4 层路由**，不再深：
- 生产首屏 → 车间详情 → 机台层 → 卷层

**车间详情**包含：当班产量、当班人、机台列表。生产流转图（原 `factory/flow`）作为车间详情的一个 section 并入，不独立成屏。

**时间维度只 3 档**：日 / 周 / 月。无"自定义日期"。

**手机/电脑差异**：手机上"按班次/按车间"切换是上下两块，电脑上是左右。

### 5.3 异常 tab

**单列时间轴**，按严重度排（红/橙/黄三级），新的在上。**不分类别 tab**。

后端融合现状的 4 个异常源（设备 / 填报 / 质量 / 同步）为一条流。每条卡片含：
- 严重度图标 + 标题 + 时间
- 一行上下文（车间 / 责任人 / 原因摘要）
- 一个主操作按钮（处置 / 追问 / 跳转 / 查看）

**顶部双计数**："待我处理 N 件 · 待车间处理 M 件"。三档过滤标签：全部 / 我的 / 已结。

**电脑版**：右侧加"处置面板"，点卡片右侧展开，不切页。
**手机版**：堆叠卡片，点进详情。

## 7. 设计原则（决策依据）

- **围绕老板的问题切**，不围绕系统功能切
- **首页 = tab 之一（今日），不再做聚合屏**——避免"首页和详情数字对不上"
- **产量与钱并排**——老板说的"都要"
- **追踪降级为搜索**——低频不占顶层
- **prose 折叠 + 数字概览展开**——老板"一眼"看全厂，要细节再看 prose
- **冻结优于立即删**——destinations / inventory / contracts 等先藏，2 周后看埋点
- **YAGNI**：不做自定义报表、自定义日期、实时大屏、数据门户、统计中心

## 8. 不在范围

- 操作端 10+ 页（下一轮）
- 编辑者（总统计）工作台 UI（任务 #9，下一轮）
- 车间主任 / 质检 / 财务 / IT 的视图（远期）
- 后端数据流、接力线 7 时间节点的自动化（编辑者工作台子任务）

## 9. 验收

- 管理端默认进入 `/today`，一屏 5 数 + 车间条 + 要紧事 + 成本 + prose 折叠
- 老板可见的顶层入口数 = 3（今日 / 生产 / 异常）+ 搜索 + 齿轮
- 现 30+ 路由全部按归位表落位，没有孤儿
- 路由旧链接 redirect 不报 404
- 手机和电脑共用一套组件代码，按宽度切布局
- 今日屏顶部数字与展开 prose 中对应字段逐字一致
- 异常 tab 不分类别 tab，单列时间轴
