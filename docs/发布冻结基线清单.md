# 发布冻结基线清单

发布冻结以代码、测试、构建、部署入口都稳定为准。

## 必须满足

- `git status --short` 不再包含测试缓存、临时截图和误生成目录。
- GitHub 远端已接入，云主机可直接拉代码。
- `python -m pytest backend/tests -q --durations=10` → `675 passed，124 deselected，30 warnings`
- `python -m pytest backend/tests -m frontend_contract -q` → `124 passed，675 deselected`
- `npm --prefix frontend test` → `119 passed`
- `npm --prefix frontend run build` → 通过
- `git diff --check` → 通过

## 冻结动作

1. 确认 `main == origin/main`。
2. 确认 `.env`、证书、备份文件不进 Git。
3. 确认生产机从 GitHub 拉取发布。
4. 确认 `/healthz`、`/readyz`、`/entry`、`/manage/factory` 通过。
