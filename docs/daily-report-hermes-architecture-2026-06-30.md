# 日报与 Hermes 架构封档 2026-06-30

## 一行行看系统

1. 一线人员扫码进入前端 `/entry`，补 MES 没有或不准的现场数据。
2. 管理人员进入 `/manage`，看大仪表盘、异常、来源和追溯。
3. 前端不直接读数据库，统一调用 FastAPI 后端接口。
4. 后端把扫码填报保存到数据中枢业务表。
5. MES 是外部生产系统，不是本产品名字。
6. MES/WMS 原库只读，系统通过适配器读取后形成投影。
7. 钉钉群文件和群聊天是最高优先级事实入口。
8. 数据中枢负责补 MES 没有的数据，也负责把来源、冲突和 trace 留住。
9. DailyFactBundle 把 MES、钉钉、扫码补录、历史日报和人工确认汇成一包事实。
10. 日报模板只从事实包取数，不在正文里临时猜数。
11. 输出 skill 文件夹里的日报正文 txt 是验收标尺。
12. 多日日报验收脚本会生成指定业务日的日报，再与输出 skill txt 做字段级比对。
13. 普通生产业务日是 07:50 到次日 07:50。
14. 铸二、铸三、热轧业务日是 10:00 到次日 10:00。
15. 内勤每日一录按 09:30 归属业务日。
16. Hermes 的工具箱包含数据中枢查询、MES/WMS 只读读取、钉钉证据、历史日报、输出 skill 对齐、来源地图和系统优化请求。
17. Hermes 是鑫泰铝业智能大脑，不是研发助手。
18. Hermes 应先主动查证，再追问最少问题。
19. Hermes 可以推动日报、异常追溯、补录、审计和系统优化闭环。
20. Hermes 的自由度不能用硬规则锁死；消息识别应宽松，不能因为格式不标准就不干活。

## 软件系统减法

1. 不新增日报门户。
2. 不新增平行的数据中枢页面。
3. 继续把管理侧收口到 `/manage` 大仪表盘。
4. 保留扫码补录、MES/WMS 投影、钉钉证据、DailyFactBundle、历史日报、审计和 trace。
5. 旧入口先冻结观察，再按来源地图删除。

## 智能体加法

1. Hermes 主动读取钉钉、MES 只读、数据中枢、历史日报和输出 skill。
2. Hermes 主动判断事实冲突，并说明采用哪个来源。
3. Hermes 主动发现日报缺字段，并要求扫码补录或从钉钉证据补齐。
4. Hermes 主动跑输出 skill 对齐验收，未通过不发正式日报。
5. Hermes 可以在 root_owner 授权下请求系统优化施工，但必须保留 trace、审计和回滚线索。

## 本轮验收口径

1. 日报准确性：最近已完成业务日的生成日报字段匹配率达到输出 skill 阈值。
2. MES 链路：Hermes 的 `mes_wms_read` 工具能调用 MES 只读服务，失败时返回可追踪原因。
3. 数据中枢链路：Hermes 的 `hub_query` 工具能拿到日报事实包。
4. 补录链路：MES 缺口不绕开扫码填报，扫码数据进入数据中枢后再进事实包。
5. 业务时间：日报和 MES 读取必须使用统一业务日窗口。

## 2026-06-30 真实生产验收结果

验收方式：

1. 本机只读读取 `D:\输出skill` 中 `2026-6-27_日报正文.txt`、`2026-6-28_日报正文.txt`、`2026-6-29_日报正文.txt`。
2. 临时复制到生产机 `/tmp`，不提交 Git。
3. 在生产机 `/srv/aluminum-bypass/backend` 用生产 `.env` 和生产数据库生成 DailyFactBundle。
4. 用输出 skill 对齐器做字段级比对。

6 月 29 日主要问题：

1. 缺 65 个字段，集中在外加工、铸轧、热轧、磨辊、能耗分项、吨耗、热轧成品率、成本口径。
2. `total_output_daily` 当前采用 `mes_packaging_output`，系统值约 384.15 吨，输出 skill 为 371 吨；包装过程量不能直接当最终日报总产量。
3. `wip_total` 当前约 1.321 吨，输出 skill 为 1136 吨；需要只读复核 MES 在制快照原始字段单位和同步口径。
4. `daily_yield_rate` 曾出现 1741.86% 这类不可能值，本轮已加保护，不再把超过 100% 的成品率投影写成正式事实。
5. 能耗和成本当前像是部分来源，不足以支撑正式日报。

处理原则：

1. 不能用输出 skill 反向改生产原始数据。
2. 未达到字段匹配阈值时，Hermes 不得宣称日报已准确。
3. 下一步先补钉钉/扫码/owner_daily 缺字段，再审计 MES 在制、产量、成品率、能耗映射。
