# 7:30 文字日报 OutputSkill 对齐基线

日期：2026-06-17

## 目标

系统每天 7:30 生成前一个已完成业务日的文字日报，正文顺序、标点、单位和字段口径对齐 `D:\输出skill\YYYY-M-D_日报正文.txt`。

## 验证命令

```powershell
cd backend
python scripts/dry_run_template_daily_reports.py --start-date 2026-06-10 --end-date 2026-06-16 --output-skill-dir D:\输出skill
```

## 当前口径

- 渲染器只打印字段值，不负责猜数。
- `D:\输出skill` 只作为验证目标，不作为运行时数据源。
- MES 只用于已经明确映射的入库、在制、冷轧/后道产量等字段。
- 热轧、铸二、铸三、铸锭、回收、大修、成品率、能耗、成本等字段优先使用结构化人工填报口径。
- `比昨日` 优先使用昨日最终日报正文里的展示值做差，不从原始数据重算。

## 待现场数据闭环

- 需要生产库里存在张兆嘉账号，并绑定钉钉用户 ID。
- 需要 2026-06-10 到 2026-06-16 的人工填报补充字段进入结构化 owner daily payload。
- 如果 dry-run 返回 `blocked`，按缺失字段分组补录，不允许用输出 skill 反向改生产原始数据。
- 如果字段匹配率低于 95%，优先检查源口径和单位换算，再检查渲染格式。
