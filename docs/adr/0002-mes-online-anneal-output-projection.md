# 在线退火产量用 MES 加工记录推算

2026-07-18 起，车间产量只认逐卷填报和责任人日报，不再用 MES 过站记录。原因是旧算法按车间名归类，把「包装」工序记录也当成了车间产量，结果比实际多出数倍。9 月下旬以后现场不再逐卷填报，日报里的车间产量因此全部缺失。2026-11-01，负责人决定：新厂在线和园区在线两条退火线的产量，在没有逐卷填报和责任人日报时，用 MES 加工记录推算。推算时排除包装工序，来源记为数据中枢推算（`workshop_output_projection`），优先级低于逐卷填报和责任人日报。其余车间继续执行 7/18 的规则。

## 依据

- 唯一能对照的正式日报是 2026-06-16 那一份（`backend/tests/fixtures/output_skill_daily_reports/2026-6-16_日报正文.txt`）。当天在线退火正式值是 253 吨，推算值是 253.3 吨（新厂北线 169.4 + 园区 83.9）。月累计推算值是 4,705 吨，正式值是 5,255 吨，少约 10%；6 月初有几天某条线没有任何 MES 记录。
- 6–9 月的逐卷填报里，同一卷退火后的重量和 MES 记录基本一致（3,166 吨对 3,171 吨）。

## Considered Options

- 同时放开 2050、1650 冷轧和拉矫：拿 6/16 正式日报核对都对不上。2050 每次轧制都算是 168 吨对 96 吨，每卷只算一次并排除转去 1650 的卷后仍多约 10%；拉矫只算拉矫工序是 142 吨对 188 吨。1650 按每卷只算一次能对上，但只验证了一天。这几项要等车间统计员说明口径，或者提供几天的实际产量来校准。
- 放开全部车间：精整、园区剪切在 MES 里同一卷的重量都对不上，或者基本只记了包装；热轧、铸轧的 MES 物料表状态码已经改成数字，数量也只有逐卷填报的一半左右；1850、彩涂在 MES 里没有记录。

## Consequences

- MES 某天漏记时，推算的月累计会偏低，日报不会提示这一点。
- 道次字段不受影响，MES 不记道次。
