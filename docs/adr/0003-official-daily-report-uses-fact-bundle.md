# 正式日报和事实闭环用同一份事实包

2026-11-01 之前，10:00 生成正式日报时，是用模板取数（逐卷填报、责任人日报、MES、能耗文件等）重新取一遍。事实闭环、看板和缺口提醒用的则是事实包：在模板取数的基础上，再叠加钉钉约定消息、授权更正和在制品沿用。恢复期里，合同、成品率、投料等字段只有钉钉约定消息这一个来源，结果事实包里有值，正式日报里却是缺失，正式日报永远生成不了。另外，事实闭环把「钉钉覆盖了低优先级来源」时留下的记录也当成冲突，发布因此被挡住。

决定：10:00 正式日报、手动生成日报和网页日报预览都改从事实包取数。事实闭环和 10:00 正式日报都不回读已经生成的日报正文，也不采信答案钥匙。只有阻塞类冲突才会挡住发布，钉钉补数、授权更正等覆盖留痕不再挡。

## Considered Options

- 在模板取数里也接入钉钉补数：同一套优先级和覆盖规则要在两处维护，以后还会再次分叉。
- 只改 10:00 这一条路径：手动重新生成时，日报会被改回模板取数的结果，网页预览和正式日报列出的缺失字段也会对不上。

## Consequences

- 网页预览指定了在制品日期时，仍然用模板取数，因为事实包只按默认的次日在制品取数。
- Hermes 的数据中枢查询工具仍然返回模板取数的结果。钉钉内容由它的钉钉证据工具单独提供。
