# 钉钉约定文件自动采信

现场责任人每天已经在钉钉里发送成品率表、剪切表、合同报表等文件，但系统只把它们存成仅机器读取（`machine_only`）证据。这类证据要人工逐条确认才能进入日报，而实际上一直没人确认，所以这些数据从未进入日报。2026-10-31，负责人决定：已登记的责任人在固定会话里发来的约定文件，只要发送人、会话、文件名格式、业务日期和数值范围都核对通过，就自动采信为事实（`specialist_sampled`），保留来源和追踪编号，事后可以纠正。没有登记的发送人或文件，仍然只作为机器读取证据。

## Considered Options

- 保留逐条人工确认：每天都要有人点确认，等于保留了一道人工统计环节，和「去统计流」的目标相反。
- 任何群成员发来的文件都自动采信：来源身份无法保证，不符合「可读取不等于可采信」。

## Consequences

- 登记信息以采样规则（`hermes_dingtalk_sampling_rules`）的形式存放在生产库，不写进代码。新增约定文件只需要登记，加上对应的确定性解析器。
- 文件内容格式变化时，解析器会返回空结果，不会猜数；这类文件仍然只作为机器读取证据。
- 2026-10-31 补充：同样的规则也适用于约定消息（`mode=registered_message`），首个约定消息是计划科刘珊珊每天发的合同和投料消息。消息按发送时间归入生产业务日，同一业务日以最后一条为准，较早的消息标为被替代。刘珊珊每天还会发一份合同报表文件，但里面的工作表都是 2021 年的旧表，日期无法确定，所以不采用。园区剪切清单记的是剪切来料，不是剪切产量，也不采用。
